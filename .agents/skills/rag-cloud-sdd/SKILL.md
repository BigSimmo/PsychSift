# RAG Cloud SDD

Read root `AGENTS.md`, canonical Cloud policy and the generated package. Keep execution provider-free;
legacy setup applies only when explicitly selected.

1. Require `TARGET_PHASE`. Confirm selected effort in ordinary language; no prompt token or
   resubmission. Run `scripts/rag-phase-launch-check.mjs` with target/effort; `--xhigh-confirmed`
   records user attestation, not runtime proof.
2. Require authoritative route evidence. Hash controller/helpers/skills; bind the fresh read-only
   probe's source/receipt inspection and dispatch metadata. Stop on unverified routes/capabilities.
3. Check receipts, dependencies and worktree conflicts; preserve unrelated work.
4. Record `TASK_BASE`; generate the brief; dispatch one fresh implementer; require decisive proof,
   self-review and completion status.
5. Commit only authorised task files. Review the entire `TASK_BASE..TASK_HEAD` range with a distinct
   reviewer returning separate specification and quality verdicts.
6. Return Critical/Important findings to the implementer; re-review the full range. Record Minor findings.
7. Require distinct phase review across `PHASE_START..PHASE_END`, route evidence and atomic accepted
   receipts. Validate; push only when authorised; stop.

P17 retains independent whole-programme review and its authorised add-only `PROGRAMME.json` commit.
Local L00–L10 keep separate approvals and never rewrite accepted Cloud receipts.
