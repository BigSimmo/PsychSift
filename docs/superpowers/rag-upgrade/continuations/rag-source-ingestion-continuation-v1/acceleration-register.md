# Safe acceleration register

Planning recommendations for future authorised work. These rows carry forward audit D1–D12 and R1–R6. Benefits are directional; no elapsed-time, cost or zero-impact guarantee. Accept an optimisation only with unchanged or improved fidelity, privacy, governance, recovery and acceptance outcomes. Preserve all required final reviews.

Development measurement: end-to-end completion, active engineering/review time, orchestration overhead, coordinator wait, correction count/severity, duplicate checks and escaped defects. Runtime measurement: stage wall/CPU time, expected/processed OCR units, image calls/cache hits, embedding tokens/batches, repeated/stale work, retry cause, fidelity outcome and operator interventions. Use synthetic local data first; provider costs and real-document measurements require separate authority.

Order optional optimisation after correctness: shared contracts and F02; safe generation/egress and actual fidelity; F16 identity; then selective reuse and measured batching. Do not make page caching, a new dispatcher or a general orchestration service a prerequisite to preserving useful evidence.
