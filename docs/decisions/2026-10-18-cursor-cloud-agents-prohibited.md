# Decision: Cursor cloud agents are prohibited

- **Status:** decided 2026-10-18
- **Source:** `AGENTS.md`, find "Never use Cursor cloud agents here"
- **Retires:** `cursor-cloud-agent-setup`

On 18 Oct 2026 the owner decided that no Cursor cloud agent (Cursor Cloud, Background Agents or any
other Cursor-hosted remote agent) may be used for this repository, for any task. The former Cursor
Cloud setup notes in `docs/agents/cursor-cloud.md` were retired and replaced by a stub.

If this summary and the source ever differ, the source wins.
