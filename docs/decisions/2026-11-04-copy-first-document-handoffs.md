# Decision: Copy-first document editing and routine handoffs

- **Status:** decided 2026-11-04
- **Source:** `AGENTS.md`, find "Prefer task-owned document drafts"
- **Source:** the owner, in chat, authorised completing the document-handoff rule rollout

Routine document work starts in a task-owned copy when it can be checked independently. The governing procedure is [Autonomous document coordination](../agents/shared-context-and-memory.md#autonomous-document-coordination); the [portable helper guide](../agents/document-drafts.md) explains the existing integrator boundary. Copying acquires no ownership of the original. Same-scope routine handoffs reuse standing permission, while substantive conflicts, protected work and publication retain their applicable authority and gates.

If this summary and the source ever differ, the source wins.
