# Decision: Only admins download original third-party PDFs until each has a licence entry

- **Status:** decided 2026-10-26
- **Source:** `src/lib/env.ts`, find "limits the original files of documents the caller does not own"

On 26 Oct 2026 the owner said "Go ahead with all recommendations" to the plan thread's question list (finding R-05). Until a source has a licence entry, only admin accounts can download its original PDF. Clinicians still see the cited excerpts in answers. The limit is on by default, and turning the setting off opens the originals again. It covers original files only. Figure crops and cover page images stay open to every signed-in user until a separate decision.

If this summary and the source ever differ, the source wins.
