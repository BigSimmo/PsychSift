# Decision: Psych Sift is one app for clinical reference and work, with nothing cut

- **Status:** decided 2026-10-21
- **Source:** `docs/product/clinical-and-work-direction.md`, find "I want it to be an all in one reference and work management tool"

The owner decided that Psych Sift stays an all in one reference and work management tool, organised
into two sides, Clinical and Work, with no Work area cut or parked. It is a reference tool without
patient data, other doctors will use it once the safety work is finished, every page stays live with
no beta labels, and no brand new areas are added for 8 weeks from 21 Oct 2026.

If this summary and the source ever differ, the source wins.
