# Decision: example content on every Work mode page when signed out

- **Status:** decided 2026-10-27
- **Source:** the owner, in chat

On 27 Oct 2026 the owner asked: "Please ensure there is sample content on all modes for me in
logged out view", "And all pages in work mode", "To demonstrate what it looks like".

Every Work mode page was opened signed out. Most already showed example records. These pages
showed only a sign-in card, and now show clearly marked example content while example data is
on (the default for a signed-out visitor; turning example data off still gives the plain sign-in
state):

- CPD: AMA CPD Home, Evidence, Export, Customise and Learning. The old CPD Job applications links
  follow on to Admin.
- Admin: Job applications and its CV, the Credential pack (built from the example records with
  made-up all-zero numbers, never the numbers saved on the device), and Contract end (an example
  contract ending five months out). The example contract is only in the signed-out example set,
  never in "Load example content", so a real account never gets an end date it did not enter.
- My Day: Alerts settings, shown as a look-only example while signed out. Signed in, they are
  always the reader's own.
- On Call: Who's on from your team roster.
- Roster: Manage team.
- Open shifts: the week board, Post, and Post a shift.

Left as they were, because they are forms or flows rather than records: Open shifts Alerts (the
same switches as Roster settings, which have nothing to show without phone alerts set up), Log a
shift, My Day Set up and Favourites, the On Call device tools, and Teaching check-in.

Nothing here can save: example screens refuse writes, as every example screen already did.

If this summary and the source ever differ, the source wins.
