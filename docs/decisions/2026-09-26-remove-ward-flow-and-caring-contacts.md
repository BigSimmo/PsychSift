# Decision: Ward Flow and Caring Contacts are retired

- **Status:** decided 2026-09-26
- **Source:** `mockups/README.md`, find "approving the plan to retire and delete Ward Flow and Caring Contacts"

Ward Flow and Caring Contacts were retired and their files removed from the project on 2026-09-26. They can be recovered from git history.

**Update 2026-10-22 (#WWTRM5).** One file under the old name is still in use: `src/lib/caring-contacts/clock.ts` is the shared Perth time helper that the Mental Health Act clock, First Nations and On Call pages import. It holds no Caring Contacts features or data, so it stays where it is. The retirement above is otherwise unchanged.

If this summary and the source ever differ, the source wins.
